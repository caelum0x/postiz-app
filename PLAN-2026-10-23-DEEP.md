# Postiz — Deep Build Plan (2026-10-23)

Internal build spec. Terse. Ground truth only (verified against source at this commit). No stubs described as done.

## Conventions
- Auth: `session` = cookie session guard (`AuthService`/org context). `apikey` = `/public/v1/*` API-key guard. `none` = unauthenticated.
- UI controls: icon/glyph buttons only, no emoji, no bare-word action buttons (e.g. a send action = arrow glyph, a confirm = check glyph, a close = × glyph).

## 2. APIs (apps/backend/src/api/routes, no global prefix; apps/backend/src/public-api for `/public/v1`)

Format: `METHOD path — auth — req → resp`.

### auth.controller.ts
- `GET /auth/can-register` — none — → `{ register: boolean }`
- `POST /auth/register` — none — `{ email, password, company?, providerToken? }` → `{ id, jwt? }`
- `POST /auth/login` — none — `{ email, password }` → `{ jwt }` (cookie set)
- `POST /auth/forgot`, `POST /auth/forgot/return` — none — email → ack / token+password → ack
- `GET /auth/oauth/:provider`, `POST /auth/oauth/:provider/redirect`, `POST /auth/oauth/:provider/exists` — none — provider OAuth bootstrap
- `POST /auth/activate`, `POST /auth/resend-activation` — session/none — code → ack
- `POST|GET /auth/farcaster/signer` — none — Farcaster signer flow

### posts.controller.ts
- `GET /posts`, `GET /posts/:id`, `GET /posts/group/:group` — session — → `Post[]`/`Post`
- `POST /posts` — session — `{ type, date, tags, posts: [{ integration, content, settings }] }` → created post group
- `PUT /posts/:id/date` — session — `{ date }` → ack
- `DELETE /posts/:group` — session — → ack
- `GET /posts/:id/statistics`, `/missing` — session — → metrics / missing-channel list
- `GET|PUT /posts/:id/release-url`, `/release-id` — session — published-URL bookkeeping
- `GET|POST /posts/:id/comments`, `POST /posts/comments/:commentId/resolve` — session — approval-thread comments
- `GET|POST|PUT|DELETE /posts/tags` — session — tag CRUD
- `GET /posts/find-slot(/:id)` — session — → next free scheduling slot
- `POST /posts/bulk-schedule`, `GET /posts/bulk-schedule/supported-providers` — session — CSV rows → created posts
- `POST /posts/generator`, `/generator/draft` — session — `{ prompt, integrations }` → AI-generated caption(s)
- `GET /posts/separate-posts` — session — per-channel content split

### integrations.controller.ts / no.auth.integrations.controller.ts
- `GET /integrations` — none — → public provider list (name, identifier, toolTip, picture)
- Connect/settings/nickname/group/custom-name endpoints — session — per-integration config
- `GET /integrations/social/:integration` — none — OAuth callback landing
- `POST /integrations/social-connect/:integration` — none — external-URL-based connect (used by `mastodon-custom`, `lemmy`, `wordpress`, `listmonk`)
- `POST /integrations/public/provider/:id/connect` — apikey — connect via public API
- `GET|POST|PUT|DELETE /integrations/plug/list(+CRUD)` — session — automation CRUD
- `GET /integrations/mentions` — session — → mentionable handles
- `POST /integrations/function` — session — plugin function dispatch (allowlisted per `third-party.controller.ts` security fix already shipped)
- `GET /integrations/telegram/updates` — session — Telegram webhook polling
- `POST|GET /integrations/moltbook/register(+status)` — session
